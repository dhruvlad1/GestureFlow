# GestureFlow

GestureFlow is a Python-based touchless computer interaction system that allows users to control the mouse cursor using hand gestures captured through a webcam.

## Tech Stack

- Python
- OpenCV
- MediaPipe
- PyAutoGUI
- NumPy

## Features

- Real-time hand tracking
- Hand gesture recognition
- Touchless cursor movement
- Mouse clicking using gestures
- Scrolling using hand gestures
- Cursor smoothing
- Gesture-based interaction
